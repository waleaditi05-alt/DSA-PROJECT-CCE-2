Tactical eSports Matchmaking & Lobby Engine

Problem Statement

To design and implement a Tactical eSports Matchmaking & Lobby Engine that matches players based on their skill levels and manages game lobbies for multiplayer games.

Objective

To develop a system for matching suitable players, forming teams, and managing game lobbies efficiently.

Data Structure Used

- Queue
- Linked List (if implemented)

Operations

1. Register Player
2. Find Match
3. Create Game Lobby
4. Display Players in Lobby
5. View Match Status
6. Exit

Concepts Used

- Programming Language (as used in the project)
- Data Structures
- Matchmaking Algorithm
- Player Management
- Team Formation
- Lobby Management
- Conditional Statements
- Loops and Functions

Algorithm

1. Start the program.
2. Register players by entering their names and skill levels.
3. Store the player details in the system.
4. Search for suitable players based on their skill levels.
5. Match the selected players and form a team.
6. Create a game lobby for the matched players.
7. Display the players present in the lobby.
8. Display the current match status.
9. Repeat the operations until the user selects Exit.
10. Stop the program.
